# Validation Log — v0.1
## Proximity Control and Actuation

**Date:** Early 2025
**Hardware:** Arduino UNO R3, HC-SR04, IRLZ44N MOSFET, 12V LED strip, 12V vibrating motor
**Status:** Validated

---

## Objectives

Validate the core control-command loop: ultrasonic proximity detection driving high-power 12V actuators (motors and LEDs) via logic-level MOSFET switching, with software signal filtering for stable output.

---

## What Was Validated

- HC-SR04 ultrasonic sensor reliably detects visitor distance across the expected operating range
- Software exponential moving average (EMA) filter eliminates sensor noise and prevents erratic actuator behavior
- IRLZ44N MOSFET switches 12V loads cleanly from 5V Arduino logic with no heating issues at operating currents
- Common ground architecture between 5V logic and 12V power rails functions correctly
- Flyback diode (1N4007) on motor load prevents inductive voltage spikes from reaching the microcontroller
- PWM modulation of LED strip produces smooth brightness transitions mapped to proximity distance
- Motor activation frequency scales correctly with proximity (intermittent at distance, rapid at close range)

---

## Known Limitations

- Single HC-SR04 sensor. Final exhibit requires 4x sensors for full piano coverage.
- Single MOSFET channel. Final exhibit requires 6x channels (3x motors, 3x LED strips).
- Arduino UNO will be replaced by RP2040-Zero for dual-core processing and I2C inter-brain communication.

---

## Hardware Configuration

| Component | Specification | Notes |
|---|---|---|
| Microcontroller | Arduino UNO R3 (ATmega328P) | 5V logic |
| Sensor | HC-SR04 ultrasonic | Trigger pin 9, Echo pin 10 |
| MOSFET | IRLZ44N | Logic-level, gate driven from Arduino PWM |
| Load | 12V LED strip + 12V vibrating motor | Common ground with Arduino |
| Protection | 1N4007 flyback diode | Across motor terminals |
| Power | 12V external supply | Arduino powered via USB during development |
